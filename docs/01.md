# Trading Signal Bot — Status Report #1

## Project Overview
Telegram-бот для сканирования крипторынка Binance, поиска сигналов BUY/SELL по техническим индикаторам и отправки уведомлений в Telegram.

## Stack
- **Python 3.12.9**, asyncio
- `python-telegram-bot` 20.7 (async)
- `ccxt` 4.2.15 (Binance)
- `pandas-ta` 0.4.71b0 (индикаторы; обновлено с 0.3.14b — несовместима с Python <3.12)
- `pandas` 3.0.3 (обновлено с 2.1.4 для совместимости с numpy 2.x)
- `numpy` 2.2.6 (обновлено с 1.26.2 — требуется новой pandas-ta)
- `SQLAlchemy` 2.0 + `aiosqlite` (SQLite)
- `APScheduler` 3.10.4 (крон-задачи)
- `Loguru` (логирование)
- Docker (python:3.11-slim + docker-compose)

## Структура

```
main.py                  # Точка входа: инициализация DB, exchange, bot, scheduler
config/
├── settings.py          # Настройки: Telegram, Exchange, Trading (все параметры индикаторов)
├── logger.py            # Loguru (консоль + файл с ротацией)
data/
├── exchange_client.py   # ccxt async client: fetch_ohlcv, fetch_all_symbols
indicators/
├── engine.py            # pandas_ta: EMA(9,21,50), RSI(14), MACD(12,26,9), ADX(14), ATR(14), Supertrend(10,3.0), Volume SMA(20)
strategy/
├── signal_engine.py     # 7 критериев, порог 4/7, SL/TP по ATR (1.5x / 3.0x)
scheduler/
├── tasks.py             # APScheduler: каждый час (:02) и каждые 4ч (:05)
├── scanner.py           # scan → evaluate → confirm (15m) → save → notify
bot/
├── handlers.py          # /start, /help, /status, /lastsignal, /symbols, /scan, /settings
├── notifier.py          # send_signal (канал), send_error_alert (админы)
storage/
├── database.py          # SQLAlchemy async: signals + bot_settings
```

## Текущее состояние
- Полностью реализован цикл: fetch → calculate → evaluate → confirm → notify
- Multitimeframe confirmation: основной сигнал (1h/4h) подтверждается на 15m
- Cooldown 60 мин на пару+таймфрейм
- 5 символов: BTC/USDT, ETH/USDT, SOL/USDT, BNB/USDT, XRP/USDT
- SL/TP рассчитываются через ATR
- Docker-инфраструктура готова
- README.md написан (RU)

## Изменения (12.05.2026)

### Проблема: проект не запускался
- Python 3.14.4 — слишком новый, большинство пакетов не имели wheels
- Зависимости не были установлены — `pip install -r requirements.txt` падал с ошибкой компиляции (нет MSVC)
- `pandas-ta==0.3.14b` удалён с PyPI

### Что сделано
1. **Установлен Python 3.12.9** (рядом с существующим 3.14.4)
2. **Обновлён `requirements.txt`**:
   - `pandas==2.1.4` → `pandas>=2.2.0` (фактически 3.0.3)
   - `numpy==1.26.2` → `numpy>=2.2.6` (фактически 2.2.6)
   - `pandas-ta==0.3.14b` → `pandas-ta>=0.4.0` (фактически 0.4.71b0)
3. **Создан `.venv`** с Python 3.12 и установлены зависимости через `--only-binary :all:`
4. **Исправлен баг в `indicators/engine.py`**: новая версия pandas-ta добавила колонку `ADXR_14_2` в ADX DataFrame, что сдвинуло индексы iloc. Исправлено на выборку по имени колонки.
5. **Все модули протестированы**: импорты, БД, индикаторы, сигналы, форматирование — без ошибок.
