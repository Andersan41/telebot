# TGBot Dashboard — план переработки

Документ описывает, какие блоки текущего дашборда меняются, зачем и как именно.
Структура: **было → проблема → стало → поля/логика**.

Общий принцип реорганизации — 4 уровня вложенности информации, от вывода к деталям:

1. Решение (Signal Header) — самое крупное, вверху
2. Контекст рынка (Market Context) — bias/режим/сила тренда, без противоречий
3. График с аннотациями (Annotated Chart) — все SMC-объекты нарисованы на цене
4. Второстепенные индикаторы (Indicators) — свёрнуто по умолчанию

Единая цветовая система на весь дашборд:
- 🟢 зелёный = бычий фактор / сигнал "за"
- 🔴 красный = медвежий фактор / сигнал "против"
- ⚪ серый = нейтрально / информационно, не сигнал

## 1. Signal Header (было: верхняя красная плашка "SELL — ПРОДАЖА")

### Было
```
SELL — ПРОДАЖА   Score: -2 | УМЕРЕННЫЙ   Вход $0.46   SL —   TP —
```

### Проблема
- SL и TP — прочерк. Сигнал без стопа/тейка бесполезен для принятия решения,
  а прочерк выглядит как баг, а не как "нет данных".
- Score "-2" ничего не говорит без разбивки: -2 из скольки, какие факторы дали минус.
- "Умеренный" — degree of what? Непонятно, это уверенность в сигнале или сила тренда.

### Стало

**Блок Signal Header, поля:**

| Поле | Было | Стало |
|---|---|---|
| Направление | "SELL — ПРОДАЖА" текстом | Крупная иконка/бейдж направления + текст, доминирующий элемент экрана |
| Score | "-2" голое число | "-2 (5 факторов против, 3 за)" + разворачиваемый список факторов с вкладом каждого (см. ниже) |
| Confidence | "УМЕРЕННЫЙ" | Явная шкала 0–100% с подписью источника: "Уверенность модели: 50%" (сейчас это дублирует поле confidence из блока Market Analysis — свести к одному месту) |
| Entry | $0.46 | Оставить, но подписать точность/источник цены (last price / mid) |
| SL | "—" | Если не рассчитан: явный текст "SL не рассчитан — недостаточно структуры" вместо тире. Если рассчитан — цена + % риска от входа |
| TP | "—" | Аналогично: текст-причина или цена + % профита от входа |
| R:R | отсутствует | Добавить обязательное поле: "R:R 1:2.3" — без него сигнал нельзя оценить |

**Разворачиваемый список факторов score** (новый элемент):
```
Факторы SELL (5):  Fib Premium zone, MSS bearish, FVG bearish mitigation, OI falling, Volume below avg
Факторы BUY (3):   Supertrend bullish, Market Trend bullish, Liquidity Sweep bullish
Score = 5 - 3 = -2
```
Это напрямую решает проблему №2 из анализа скриншота — пользователь видит зелёный Supertrend
и зелёный Market Trend, но красный итог, и не понимает почему. Список факторов снимает вопрос.

## 2. Market Context (было: разрозненные "Вердикт / Режим / Сила тренда")

### Было
```
Вердикт: УМЕРЕННЫЙ (увер. 50%)
Режим: —
Сила тренда: Слабый (ADX/Supertrend)
```

### Проблема
- "Режим" — пустое поле с тире, дыра в интерфейсе.
- "Вердикт" дублирует Score/Confidence из шапки — два источника одной информации.
- Нет ни одной фразы, которая явно снимает противоречие между краткосрочным
  Supertrend (Bullish) и итоговым SELL.

### Стало

**Блок Market Context, поля:**

| Поле | Было | Стало |
|---|---|---|
| Вердикт | дублирует шапку | Удалить, оставить только в Signal Header |
| Market Regime | "—" | Обязательное значение из фиксированного набора: `Trend / Range / Volatile / Squeeze`. Если не вычисляется — скрыть блок целиком, а не показывать тире |
| Сила тренда | "Слабый (ADX/Supertrend)" | Оставить, но добавить таймфрейм: "Слабый (ADX 13.9, 1H)" |
| **Объяснение конфликта** | отсутствует | Новое поле-фраза, генерируется автоматически: *"Краткосрочный тренд (1H Supertrend) — бычий, но HTF-структура (Fib Premium zone + MSS bearish) медвежья → сигнал идёт против локального тренда, риск повышен"*. Это одно предложение убирает главную путаницу дашборда |
| HTF Bias | отсутствует на скрине | Добавить отдельно: bias по 4H/1D с направлением, чтобы понять, откуда взялся SELL при бычьем 1H |

## 3. Price Action Chart (было: маленький график без аннотаций)

### Было
Свечной график 1H с двумя горизонтальными линиями ($0.46 / $0.46 — дублируются),
S1/S2 подписаны сбоку, но Order Block / FVG / Sweep / Fibonacci-зона живут
отдельным текстовым списком справа и никак не связаны с графиком визуально.

### Проблема
- Пользователю приходится вручную сопоставлять цифры из списка ("$0.42 — $0.43")
  с картинкой графика.
- Две одинаковые линии "0.46 / 0.46" — вероятно, entry и текущая цена совпали,
  но это не подписано, выглядит как дублирование бага.
- Support/Resistance даны как качественные метки ("Средний"), без дистанции в %
  от текущей цены — непонятно, насколько уровень актуален прямо сейчас.

### Стало

**График становится основным носителем SMC-данных, а не текстовый список:**

| Объект | Было (текстом справа) | Стало (на графике) |
|---|---|---|
| Order Block | строка "Бычий @ $0.46 — Поддержка" | Прямоугольник на графике в зоне OB, зелёная заливка, подпись при наведении |
| Fair Value Gap | строка "$0.42 — $0.43 — Магнит" | Заштрихованная зона между уровнями на графике, подпись "FVG" |
| Liquidity Sweep | строка "Бычий sweep detected — Цель" | Стрелка/маркер на конкретной свече, где произошёл sweep |
| Fibonacci / Premium-Discount Zone | строка "Fib 54.0% · $0.44–$0.45 — Премиум" | Горизонтальная зона на графике с градиентом premium/discount + подпись текущего fib-уровня |
| Support / Resistance | "$0.4579 Средний" | Горизонтальная линия на графике + **дистанция от текущей цены в %** вместо/вместе с качественной меткой: "$0.4579 · +1.5% от цены · тест x2" |
| Dealing Range | строка "High $0.48 / Low $0.43" | Верх/низ диапазона отмечены на графике тонкими линиями, текущая позиция цены в диапазоне — прогресс-бар (сейчас "10.4%" висит без графической привязки) |

**Текстовый список справа не убирается полностью**, а превращается в **легенду к графику**:
клик по строке в списке подсвечивает соответствующий объект на графике. Информация
не дублируется как два независимых источника, а один явно ведущий (график), второй —
навигация по нему.

## 4. Smart Money Panel (было: список с разноцветными бейджами)

### Было
```
Order Block (ордер блок)       Бычий @ $0.46          Поддержка   (зелёный)
Fair Value Gap (честный разрыв) $0.42 — $0.43          Магнит      (жёлтый)
Liquidity Sweep (смыв ликвидности) Бычий sweep detected Цель        (красный)
Market Trend (тренд рынка)      Бычий                  Бычий       (зелёный)
Fibonacci Zone (Премиум)        Fib 54.0% $0.44-$0.45  Премиум     (красный)
Dealing Range (диапазон)        High $0.48 Low $0.43   10.4%       (серый)
Расстояние до зон                До премиума 5.0% / До дисконта 5.9% Дистанция (жёлтый)
```

### Проблема
Шесть цветных бейджей справа — "Поддержка", "Магнит", "Цель", "Бычий", "Премиум",
"Дистанция" — используют цвет для совершенно разных смыслов: где-то это
bullish/bearish сигнал, где-то это просто категория описания, где-то — статус
близости. Цвет перестаёт нести сигнальную нагрузку, потому что применяется
непоследовательно.

### Стало

Разделить на две колонки с разным назначением цвета:

1. **Колонка "Факт"** — что это за объект и где он (нейтральный серый текст,
   без цветового кодирования: Order Block @ $0.46, FVG $0.42–0.43, и т.д.)
2. **Колонка "Влияние на сигнал"** — используется **только** единая
   зелёный/красный/серый система из общего принципа документа:
   - зелёный бейдж = фактор говорит "за лонг"
   - красный бейдж = фактор говорит "за шорт"
   - серый бейдж = чисто информационный факт без сигнальной нагрузки (например,
     Dealing Range сам по себе не бычий и не медвежий — это просто диапазон)

Ярлыки "Магнит"/"Цель"/"Дистанция" убираются как самостоятельные цветные бейджи —
это описательные слова, а не сигналы, и их не нужно красить в цвета, конкурирующие
с реальными bullish/bearish пометками. Вместо них — просто текст в колонке "Факт".

**"Расстояние до зон"** объединяется с блоком Dealing Range/Fibonacci Zone
(п. 3, график), а не живёт отдельной строкой в списке — это одна и та же
информация о позиции цены в диапазоне, поданная дважды.

## Итоговая структура страницы (сверху вниз)

1. **Signal Header** — направление, score с разбивкой факторов, confidence, Entry/SL/TP/R:R
2. **Market Context** — режим рынка, сила тренда, HTF bias, фраза-объяснение конфликта трендов
3. **Annotated Price Chart** — цена + OB/FVG/Sweep/Fib-зоны/S-R как графические объекты, переключатель Price/CVD
4. **Smart Money Panel** — список объектов графика с единой цветовой кодировкой факт/влияние
5. **Indicators (свёрнуто)** — RSI/MACD/EMA/ADX/Supertrend/Volume/OI/Funding под одним спойлером с таймфреймом

## Общие правила для всех блоков

- Никаких пустых полей с "—" без подписи причины. Либо значение, либо явный
  текст "недоступно / не рассчитано / недостаточно данных".
- Один смысл — один цвет. Зелёный/красный/серый используются только для
  bullish/bearish/нейтрально и нигде больше (не для "важности", не для
  "категории объекта").
- Каждая метрика, зависящая от таймфрейма, подписывает таймфрейм явно.
- Любая информация, которая уже есть на графике (уровни, зоны, диапазон),
  не дублируется отдельным текстовым блоком как второй независимый источник —
  текст становится легендой/детализацией графика, а не копией.
