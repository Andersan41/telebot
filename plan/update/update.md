### 1.1 Конфликт между силой сигнала и вердиктом ✅ СДЕЛАНО

**Проблема:****
Бот одновременно выдаёт:
- Сила сигнала: ⭐️⭐️⭐️⭐️⭐️ (7/8)
- Вердикт: WEAK (уверенность 19%)

Это логическая ошибка. Две метрики считаются по разным формулам и не связаны между собой.

**Что сделать:**
- Определить ОДНУ итоговую метрику уверенности
- Сила сигнала (7/8) должна напрямую влиять на итоговый вердикт
- Вердикт WEAK при 7/8 недопустим — пересмотреть пороговые значения:

```
0–3/8  → WEAK
4–5/8  → MODERATE  
6–7/8  → STRONG
8/8    → VERY STRONG
```

- Убрать дублирование: либо показывать звёзды, либо вердикт — или объединить в одну строку:
  `💪 Сигнал: STRONG (7/8) — уверенность 74%`

### 1.2 Неправильная трактовка Fear & Greed ✅ СДЕЛАНО

**Проблема:**
Fear & Greed = 27 (Fear) засчитывается как ✅ позитивный фактор для лонга.

**Что сделать:**
Изменить логику интерпретации F&G:

```
Для лонга:
  F&G < 20 (Extreme Fear) → ✅ контртрендовая возможность
  F&G 20–40 (Fear)        → ⚠️ нейтрально, осторожно
  F&G 40–60 (Neutral)     → ✅ нейтрально
  F&G 60–80 (Greed)       → ⚠️ риск перегрева
  F&G > 80 (Extreme Greed)→ 🔴 не входить в лонг

Для шорта — логика зеркальная.
```

F&G = 27 для лонга → должно быть ⚠️, а не ✅.

### 1.3 Long/Short Ratio игнорируется в итоговом счёте ✅ СДЕЛАНО (уже реализовано)

**Проблема:**
L/S = 1.02 помечен ⚠️, но в вердикте засчитаны 3 галочки ✅ из рыночного контекста, как будто предупреждения нет.

**Что сделать:**
- ⚠️ факторы должны снижать итоговый скор, а не игнорироваться

```
✅ = +1 балл
⚠️ = 0 баллов (нейтрально, не плюс)
🔴 = -1 балл
```

### 2.3 Проверка уровней относительно SL/TP ✅ СДЕЛАНО

После расчёта уровней — автоматически проверять:

```python
def validate_levels_vs_trade(sr_levels, entry, sl, tp, timeframe='1h'):
    """
    Проверяет, не находится ли сильный уровень сопротивления между входом и TP
    """
    warnings = []
    resistances = sr_levels.get(timeframe, {}).get('resistance', [])
    
    for r in resistances:
        if entry < r < tp:
            warnings.append(
                f"⚠️ Уровень сопротивления {r} находится между входом и TP на {timeframe}!"
            )
    
    supports = sr_levels.get(timeframe, {}).get('support', [])
    for s in supports:
        if sl < s < entry:
            warnings.append(
                f"⚠️ Уровень поддержки {s} находится между SL и входом на {timeframe} — SL может быть слишком близко."
            )
    
    return warnings
```
