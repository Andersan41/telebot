# 9. Возможные улучшения и накопленный долг

## Недавно исправлено (см. git log)

- ✅ Funding rate — переведён на прямой HTTP `fapi/v1/premiumIndex`, больше не
  завязан на сломанный ccxt spot-вызов.
- ✅ OI delta — реально считается процентное изменение относительно предыдущего
  значения per-symbol (in-memory `_last_oi`).
- ✅ CONTEXT_MIN_VERDICT — реализован ранговый гейт в `scanner.scan_symbol`.
- ✅ `signal_engine.format_message` — корректный знаменатель `/6`.
- ✅ Дубль cron-джобов — `_scan_job` параметризован, 1H/4H теперь разнесены.
- ✅ Race на `news_sentiment_score` — аккумуляция CryptoPanic+RSS после
  `asyncio.gather`, средневзвешенный итог.
- ✅ `db.save_signal(confirmed=…)` — отражает реальный результат 15M-фильтра.

## Открытые улучшения

### Архитектура

- **Параметры индикаторов в .env.** Сейчас захардкожены в `TradingConfig`. Дать
  возможность изменять без правки кода.
- **OI delta после рестарта.** Сейчас при старте процесса первая дельта = 0.0.
  Можно подтягивать историю из `fapi/v1/openInterestHist`, либо хранить
  последнее значение в БД.
- **OI-шкала для SELL.** В `_score_oi` направление сигнала игнорируется — для
  SELL рост OI оценивается так же, как для BUY. Если это намерено, то
  задокументировать; иначе — зеркалить.
- **Cooldown в БД, а не в памяти.** Сейчас словарь обнуляется при рестарте.
- **Подтверждение 15M в `_do_full_analysis`.** Меню показывает сигнал без
  confirmation — добавить или явно помечать «preview, без 15M-фильтра».
- **Score-формула.** Учесть ADX и DMI как реальные критерии, а не только
  reasons. Или формализовать «6 факторов + ADX-фильтр».

### Тесты / DX

- **Прогнать существующий `pytest` в CI.** Тесты `tests/test_*.py` уже есть,
  в плане их раздел отсутствует.
- **Нет тестов на context-модуль** для новых формул (OI delta, news race).
- **Нет CI/CD.**
- **Нет мониторинга/алертинга** (кроме фатальных `send_error_alert`).
- **Нет rate limiting** на команды.
- **Нет метрик Prometheus.**
