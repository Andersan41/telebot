# F1.2: Фоновый outcome_tracker loop

> **Статус**: 🔴 не сделано
> **Приоритет**: 🟠 high — ядро трекинга SL/TP
> **Зависимости**: F1.1 (модель + CRUD в БД)

**Цель**: создать фоновую задачу, которая опрашивает биржу и закрывает outcome'ы при HIT TP/SL или TTL expiry.

**Файлы**:

| Файл                             | Что делать                                               |
|----------------------------------|----------------------------------------------------------|
| `scheduler/outcome_tracker.py`   | новый файл: `check_open_outcomes()`, `outcome_tracker_loop()` |
| `main.py`                        | `asyncio.create_task(outcome_tracker_loop())` при старте |

**Пошагово**:

1. Создать `scheduler/outcome_tracker.py`:
   - Константы из env: `OUTCOME_CHECK_INTERVAL_SECONDS` (300), `OUTCOME_TTL_DAYS` (7)
   - `check_open_outcomes()`:
     - Получить OPEN outcomes через `db.get_open_outcomes()`
     - Для каждого: получить сигнал через `db.get_signal()`
     - Если возраст > TTL → `EXPIRED`, close_price = signal.close_price, pnl=0
     - Иначе: `fetch_ohlcv(symbol, "1m", limit=2)` → последняя свеча
     - Проверка TP/SL по direction (BUY/SELL)
     - HIT → `close_outcome` с pnl_pct
   - `outcome_tracker_loop()`: while True → check → sleep

2. Зарегистрировать в `main.py` после инициализации бота.

**Edge cases**:
- ccxt rate limits — если > 20 open outcomes, батчить через `fetch_tickers`
- Двойное закрытие — `get_open_outcomes` фильтрует `status == "OPEN"`
- Биржа упала — `fetch_ohlcv` → `None`, скип, повтор через interval
- 1m `close` ≠ реальная цена пробоя — для строгости брать `high`/`low` свечи

**Готовность**:
- `pytest tests/test_outcome_tracker.py -v` — 10 тестов проходят
- `pytest -v` — все зелёные

**Тесты** (`tests/test_outcome_tracker.py`):
```
TestHitTP:
  - buy_hit_tp: цена 112 > TP 110 → HIT_TP, pnl > 0
  - sell_hit_tp: цена 88 < TP 90 → HIT_TP, pnl < 0 (отрицательный для SELL)

TestHitSL:
  - buy_hit_sl: цена 93 < SL 95 → HIT_SL, pnl < 0
  - sell_hit_sl: цена 107 > SL 105 → HIT_SL, pnl > 0

TestNoHit:
  - price_in_corridor: цена 105 между SL/TP → остаётся OPEN

TestExpired:
  - expired_signal: created_at 8 дней назад → EXPIRED

TestGetOutcomeStats:
  - empty_stats: без записей → все нули
  - mixed_results: 1 HIT_TP + 1 HIT_SL → wins=1, avg_pnl != 0

TestFetchError:
  - fetch_returns_none → outcome остаётся OPEN
  - fetch_returns_empty → outcome остаётся OPEN
```
