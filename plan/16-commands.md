# 8. Команды Telegram (полный список)

## Slash-команды

Регистрируются в `bot/handlers.py:138-149` (`register_handlers`).

| Команда      | Доступ | Описание                       |
|--------------|--------|--------------------------------|
| `/start`     | Все    | Главное меню с inline-кнопками |
| `/help`      | Все    | Справка                        |
| `/status`    | Все    | Статус бота                    |
| `/lastsignal` | Все   | Последние 5 сигналов           |
| `/symbols`   | Все    | Список символов (read-only)    |
| `/scan`      | Admin  | Ручной запуск сканирования     |
| `/settings`  | Admin  | Настройки индикаторов          |

## Меню (inline-кнопки + текстовый ввод)

`/start` (а также неявный алиас `/menu`, обрабатываемый в `bot/menu.py:161` как тот же
`send_main_menu`) показывает 4 кнопки. Callback'и обрабатываются в
`bot/menu.py:handle_menu_callback` (зарегистрирован как `CallbackQueryHandler` в
`bot/handlers.py:147`). Произвольный текст (например, токен в режиме «Анализ») идёт через
`MessageHandler(filters.TEXT & ~filters.COMMAND, handle_menu_message)` (`handlers.py:148`).

| Кнопка               | Действие                                                          |
|----------------------|-------------------------------------------------------------------|
| 📊 Анализ токена     | Запрашивает текстом символ (`BTC/USDT`), показывает полный анализ |
| 📉 Индикаторы        | Выводит расчёт индикаторов на 1H без сигнальной части             |
| 🚀 Авто-скан всех    | Запускает `run_scan_cycle` по всем сконфигурированным символам    |
| ⚙️ Настройки          | Показывает текущие `TradingConfig`-параметры                      |
